# AgentRQ on iPhone and iPad

AgentRQ runs as an app on your iPhone or iPad without the App Store. You add the web app to your Home Screen, and it then opens full screen like any other app and can send you push notifications.

## Installing

1. Open your AgentRQ server in **Safari** and sign in.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open AgentRQ from its Home Screen icon. The installed app keeps its own sign-in, separate from Safari, so it may ask you to sign in once more.

The first time you sign in from Safari, AgentRQ shows a short note with these steps. It shows that note only once.

## Push notifications

iOS lets a web app send notifications only once it is on the Home Screen, so install it first. Then:

1. Open AgentRQ from its Home Screen icon.
2. Go to a workspace's **Settings → Notifications** and tap **Enable Push**.
3. Allow notifications when iOS asks.

Push is set per workspace, so repeat step 2 for each workspace you want to hear from. In Safari, before you install, that page tells you to add AgentRQ to the Home Screen instead of showing **Enable Push**.

Push also needs your server to have Web Push keys configured. If **Enable Push** does not appear in the installed app, ask whoever runs your server.

## Updates

The app updates itself. When a new version is ready, a bar at the top offers **Update now**.
